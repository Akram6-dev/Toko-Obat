FONDASI SISTEM

Bab 0: Fondasi Database & Kelas Inti

Sebelum masuk ke tampilan halaman, aplikasi butuh koneksi database SQL Server dan sistem untuk mengingat siapa pengguna yang sedang login.

Struktur Database SQL Server (tokoobat.sql)

Skema Tabel Utama Apotek DATABASE SCHEMA
Buat apa fungsi ini? Mendefinisikan 6 tabel utama: Users (akun pegawai & role), Produk (stok & harga obat), Pelanggan (data customer), Transaksi (header penjualan), DetailTransaksi (item obat yang terjual), dan LogAktivitas (rekam jejak seluruh aksi).
tokoobat.sql — Skema Tabel Utama Apotek 
-- Tabel Akun Pengguna (Admin, Kasir, Owner)
CREATE TABLE Users (
    Id INT IDENTITY(1,1) PRIMARY KEY,
    Nama VARCHAR(100) NOT NULL UNIQUE,
    Password VARCHAR(255) NOT NULL,
    Role VARCHAR(50) NOT NULL,
    FotoProfil VARBINARY(MAX) NULL
);

-- Tabel Data Obat / Produk
CREATE TABLE Produk (
    Id INT IDENTITY(1,1) PRIMARY KEY,
    IdAdmin INT NOT NULL,
    Nama VARCHAR(100) NOT NULL,
    Category VARCHAR(100) NOT NULL,
    TanggalKadaluarsa DATE NOT NULL,
    Stok INT NOT NULL,
    Jenis VARCHAR(50) NOT NULL,
    Harga VARCHAR(50) NOT NULL,
    FotoProduk VARBINARY(MAX) NULL,
    Deskripsi VARCHAR(255) NULL
);

-- Tabel Transaksi Kasir
CREATE TABLE Transaksi (
    Id INT IDENTITY(1,1) PRIMARY KEY,
    IdKasir INT NOT NULL,
    IdPelanggan INT NULL,
    TotalProduk INT NOT NULL,
    Harga_Total INT NOT NULL,
    Uang_Bayar INT NOT NULL,
    Uang_Kembali INT NOT NULL,
    Tanggal_Transaksi DATETIME DEFAULT GETDATE()
);
